# BFS, DFS & A* Search Graph Representation

A lightweight Python module implementing graph search and pathfinding algorithms.

## Features
- **Breadth-First Search (BFS)**
- **Depth-First Search (DFS)**
- **A* Search Algorithm** (with custom heuristic support)
